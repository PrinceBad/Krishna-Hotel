# Krishna Hotel & Restaurant Website

A premium, fully responsive, and modern single-page web application designed for **Krishna Hotel & Restaurant**, located in Sector 48, Sonipat, Haryana. 

The website highlights the premium hospitality, cozy deluxe rooms, and multi-cuisine restaurant services with smooth animations, curated HSL-tailored colors, and rich typography.

---

## 🌟 Key Features

- **Premium & Modern Aesthetics**: Tailored color palette using Culinary Crimson (`#8D2B1F`), Warm Golden Amber (`#D97706`), Soft Vanilla Cream, and Rich Espresso Cocoa.
- **Glassmorphism Navigation**: Floating navigation bar with smooth backdrop filters and responsive mobile toggle drawer.
- **Dynamic CSS Animations**: Elegant keyframe transitions (`fadeInUp`, `fadeInDown`) and interactive scaling on hover states.
- **Services Grid**: Fully responsive service card layouts highlighting deluxe accommodations, multi-cuisine restaurant offerings, free parking, high-speed WiFi, and takeaway services.
- **Photo Gallery**: Beautiful CSS Grid showcase displaying rooms, dining space, and mouth-watering culinary delights.
- **Customer Reviews Section**: Interactive review cards featuring ratings and customer feedback.
- **Interactive Booking & Contact Form**: Fully stylized inquiry form for reserving tables or room bookings.
- **SEO Optimized**: Formatted semantic HTML5 structure, descriptive meta headers, custom responsive viewport configurations, and unique, accessible identifiers.

---

## 🛠️ Technology Stack

- **Core**: Semantic HTML5 & Vanilla JavaScript
- **Styling**: Modern CSS3 (featuring HSL tailored colors, CSS Grid, Flexbox, custom variables, keyframe animations, and custom scrollbars)
- **Typography**: Google Fonts Integration ([Playfair Display](https://fonts.google.com/specimen/Playfair+Display) & [Poppins](https://fonts.google.com/specimen/Poppins))
- **Icons**: Emoji & Custom SVG Icons

## 🚀 How to Run Locally

Since this is a lightweight frontend application using static assets, there are no build steps required!

1. **Clone or Download** this directory to your local machine.
2. Open `index.html` in any web browser (Google Chrome, Firefox, Microsoft Edge, Safari) by double-clicking it.
3. *Alternative (Recommended)*: Use a local development server extension like **Live Server** in VS Code to run the site with automatic reloading on edits:
   ```bash
   # If you have a static server installed globally:
   npx serve .
   ```
